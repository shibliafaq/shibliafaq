---

### Current work

**M.Sc. Thesis — Smart Digital Twin for UHI Monitoring & Mitigation**
Real-time satellite pipeline (GEE → Kafka → PySpark → PostGIS) covering 5 Saudi cities. 48-hour LST forecasting with Facebook Prophet (<1.5°C RMSE target). Heat Vulnerability Index mapping 100,000+ at-risk residents.

**GIS & Remote Sensing UHI Assessment — Dammam Metropolitan Area**
12,954 grid cells across 3,238 km². NDBI confirmed as dominant LST driver (R²=0.511, 35× stronger than NDVI). 57.3 km² urgent intervention zone identified. Paper under departmental review → target: *Urban Climate*.
